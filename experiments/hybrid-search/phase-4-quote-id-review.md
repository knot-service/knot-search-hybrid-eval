# 4단계 · 구절 ID로 원문 인용 보존

2026-11-12. Workspace 1과 Workspace 458 v1.30에서 기존 문장 복사, 구절 ID와 세 문서 제한, 구절 ID 채택안의 실제 Spring 탐색 POST를 비교했다. 변형별 74건으로 진단 4문항을 3회, 이전 정답 대조 15문항과 문서 찾기 47문항을 1회 실행했다. 문서 스냅샷과 기준 시각을 맞췄다. 생성 요청마다 구절 ID와 공백을 제외한 문서·발췌·질문·대화 입력이 일치했다. 기존 검색 서비스 타임아웃 1건은 동일 조건에서 재실행했다. 요청 ID가 재사용된 별도 예비 실행은 집계에서 제외했다.

기존 W1-0174-01에서 Qwen은 전사 보류를 3회 모두 답에 썼다. 복사한 인용은 문서 596에서 전달된 연속 구절과 일치하지 않아 Spring이 세 주장을 모두 제외했다. 변경 후 Spring은 선택된 원문 발췌에 구절 ID를 붙이고, 모델이 돌려준 문서·구절 ID 조합이 이번 요청의 근거에 속하는지 확인한 뒤 해당 원문을 답변에 붙인다.

세 문서 제한을 유지한 중간 후보에서는 W1-0284-03의 408 구절 ID가 유효했어도 1회에서 네 번째 문서라는 이유로 408이 붙은 두 주장이 빠졌다. 채택안은 답변 전체의 문서 세 개 제한을 없앴다. 최대 6개 주장과 주장당 최대 2개 구절로 응답을 제한하며, 미등록 ID나 다른 문서의 ID를 붙인 주장은 검증에서 제외한다.

채택안에서 발췌와 일치하지 않는 구절 ID는 97개 중 0개였다. 문서 찾기 47건은 전후 검색 출처 순서가 일치했다. W1-0062-06은 날짜·토픽 탐색 제안과 구체 화면 방식 미정을 원문 인용과 함께 전달하도록 회복됐다. W1-0189-04는 최종 선택 미정과 기능 하나를 고른다는 방침은 보존했으나, 논의된 세 후보를 빠뜨렸다. W1-0284-03은 408의 원문을 세 번 모두 인용했지만 두 번은 레거시 독스 등의 구절을 선택하고 필수 ADR 유지 구절을 선택하지 않았다.

각 변형의 실제 생성 27건 기준으로 평균 입력 토큰은 문장 복사 5,769개, 채택안 6,201개였고 평균 출력 토큰은 259개에서 197개로 줄었다. 백엔드 관련 테스트 56개가 통과했다. 여기에는 미등록·타 문서 구절 ID 거절, 네 문서의 유효한 인용 보존, 회의 시각과 실제 발췌 유지 검증이 포함된다.
