# 4단계 후속 · 본문 출처 표기와 인용 카드

2026-11-12. 생성 응답의 주장 텍스트에 남은 `E408`·`E408Q1` 표기를 검증된 출처 제목으로 바꾼다. 제목을 연결할 수 없으면 “회의 기록”으로 표시한다. 인용 구절은 원문 그대로 보존한다. 이전에 저장된 구조화 답변도 탐색 화면에서 본문 표기를 바꿔 보여준다.

메시지 목록과 SSE가 공통으로 읽는 출처 조회에서 세 장 제한을 제거했다. 답변에 저장된 출처를 순서대로 보여준다. 문서 찾기는 기존대로 최대 세 문서를 저장하고 생성 모델을 호출하지 않는다.
