# 2단계 · 결정 상태와 필수 사실 보존

2026-11-12. Workspace 1과 Workspace 458 v1.30에서 실제 Spring 탐색 POST와 Qwen 답변을 재생했다. 실험 목적은 문맥에 있는 필수 사실을 답변과 인용에 함께 남기고, 문서마다 다른 결정 상태를 정확하게 귀속시키는 것이다.

## 방법

- 진단 4문항을 변형별 각 3회, 이전에 정답이었던 대조 문항 15개를 각 1회, 문서 찾기 47문항을 각 1회 재생했다. 변형당 74요청이다. 문서 찾기에는 Workspace 1의 35건과 Workspace 458의 12건이 들어간다.
- 변형 간 문서 스냅샷, 질문·대화 이력, 생성 모델, 검색 설정을 맞췄다. 로컬 구절 ID 실험은 평가셋 기준 시각을 재사용했다. 브랜치 검증은 실제 요청 시각을 사용했다. Qwen에 실제 전송한 사용자 메시지 JSON을 문항·반복별로 비교해 검색 문서 순서와 발췌가 같음을 확인했다.
- 필수 사실 판정은 질문에 대한 직접 답과 평가셋 기대 설명을 함께 확인했다. 이전 정답 대조군에서도 조건이나 미정 사항이 빠지면 미충족으로 집계했다.
- Qwen이 작성한 구조화 주장, Spring 검증을 통과한 주장, 저장 출처, SSE에 표시된 상위 출처를 대조했다. 인용 원문 일치는 DB 문서의 문자열로 검사하고, 상태·필수 사실과 주장별 출처 지지는 원문을 직접 읽어 판정했다.
- 구절 ID를 사용하는 로컬 구현에서 두 후보를 탐색했다. 원격 브랜치 `0008a8c2`의 원문 직접 인용 구현에서도 두 번째 후보를 별도로 비교했다.

W1-0140-02는 어느 기록인지 지정하지 않은 질문이다. 이전의 일괄 확정 오답은 이번 기존 프롬프트 재생에서 나오지 않았다. 문서 577은 최종 채택 미정, 578은 결정으로 기록돼 있고, 두 문서는 같은 회의의 별도 주제 문서다. 기존의 한 답변과 후보 1의 세 답변은 이를 별개 회의로 표현했다. 후보 2는 세 번 모두 문서 제목으로 상태를 구분하고 양쪽 출처를 인용했다. 이 비교에서는 평가셋의 577 미정 기대를 유지하면서 578의 다른 기록을 명시하는 답도 충족으로 판정했다.

후보 1은 Workspace 1 대조군에서 2건을 회복하고 1건에서 새 누락을 만들었다. 후보 2는 회복과 신규 누락이 각각 0건이었다. 기존에 정답이었던 대조군도 새 생성에서 일부 누락을 보였으므로, 신규 회귀는 같은 조건으로 다시 생성한 기존 답변과 비교했다.
