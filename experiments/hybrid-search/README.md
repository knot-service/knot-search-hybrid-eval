# Workspace 검색 비교

기존 Knot 탐색 평가실의 **하이브리드 검색 실험** 메뉴에서 검색 방식 비교, 문서 찾기, 회의 종합을 실행한다. 이 폴더의 Python 실행기는 로컬 포트 18173으로 연결된다. 기준 브랜치는 Knot `be/refactor/#715`의 `cb08773ab`다.

## 로컬 실행

이 폴더에서 Python 3.12와 Docker를 사용한다.

```sh
uv venv --python 3.12
uv pip install -r requirements.txt
.venv/bin/python database.py prepare
docker compose --project-name knot-hybrid-search up -d --wait
.venv/bin/python snapshot.py /path/to/knot-search-lab/experiments/workspace458-v130-separate-fixture-crosswalk-20261111.json
.venv/bin/python database.py .local/workspace458.json
KNOT_EVAL_ENV_FILE=/path/to/knot/backend/.env.search-local ./launch-local.sh
```

458은 기존 Playground DB에서 현재 합성 멤버 1의 DRAFT·ARCHIVED 문서를 조회한다. Eval DB의 잠긴 v1.30에서 질문과 기대 근거만 읽고, 별도 실행 조건이나 대화 이력이 필요한 사례와 기대 근거가 없는 사례를 제외한다. 두 소스는 읽기 전용으로 조회한다. 생성 요청에는 기존 Eval의 `LLM_*` 설정을 사용한다.

별도 PostgreSQL은 로컬 55448에서 실행되고 `workspaces.id`로 코퍼스를 구분한다. 운영 Workspace 1을 가져올 때는 권한이 확인된 연결에서 `psql -XqAt -v ON_ERROR_STOP=1`로 `workspace1.sql`을 실행하고, 출력은 권한 600의 `.local/workspace1.json`으로 받는다. `.venv/bin/python database.py .local/workspace1.json`으로 로컬 DB에 가져온 뒤 작업용 덤프 파일을 삭제할 수 있다. 운영 덤프에는 검색용 문서와 녹음 시작 시각만 들어간다. 현재 실행기는 합성 458에만 질의하고 Qwen에도 458 근거만 보낸다.

## 비교 조건

- 기준 시각은 2026-11-11 00:00 KST다. 90개 합성 문서와 기대 근거가 있는 단일 턴 55개 질문을 사용한다.
- 세 방식은 제목·주제·요약을 공통 검색 표현으로 쓴다. 요약이 비면 본문 앞 750자를 사용한다. 키워드는 BM25, 벡터는 CPU에서 multilingual-e5-small로 임베딩한 뒤 pgvector에서 정확 코사인 검색, 하이브리드는 각 방식의 상위 20개를 RRF로 결합한다.
- 측정은 문서 단위 Recall@10, 모든 기대 근거 포함률, 검색 p50·p95다. 검색 시간은 벡터 모드의 질문 임베딩을 포함한다. 하이브리드 시간은 두 검색과 결합의 합이다. 프로세스 시작과 문서 임베딩은 검색 시간에서 제외한다.
- 문서 찾기는 녹음 시각과 배포·안정성 주제로 가장 최근 회의를 찾은 뒤 하이브리드 후보를 반환한다. 종합은 같은 기준의 최근 세 회의에서 한 건씩 근거를 뽑아, 본문의 관련 단락과 요약을 Qwen에 제공한다.
- 실행 결과는 `.local/runs/`에 기록한다. 첫 모델 응답 시간은 실행 시작부터 첫 내용 토큰까지다. 화면에는 전체 응답 수신 후 답변과 출처를 표시한다.

## 2026-11-11 첫 비교 결과

Chrome에서 실행한 55문항 비교 `f831b1c88db5424fba38ecfbb957c02c`의 결과다.

| 방식 | Recall@10 | 모든 기대 근거 포함 | 검색 p50 | 검색 p95 |
| --- | ---: | ---: | ---: | ---: |
| BM25 | 52.7% | 49.1% | 0.128 ms | 0.234 ms |
| 벡터 | 80.6% | 78.2% | 15.072 ms | 43.438 ms |
| RRF 하이브리드 | 79.1% | 76.4% | 15.207 ms | 43.616 ms |

RRF는 벡터 단독 대비 53개 사례에서 같은 Recall@10을 기록했고 2개에서 떨어졌다. `S19-01`, `S69-02`에서 기대 문서 2207이 상위 10개 밖으로 밀렸다. 이 55개는 검색 품질을 비교할 수 있는 부분집합이며, 답변 정확도나 운영 지연을 대표하지 않는다.

- 문서 찾기 `e301b33b8a384c719484335447abff09`는 문서 2154를 반환했다. 생성 모델 호출은 0회, 실행기 처리 시간은 21.1 ms였다.
- 회의 종합 `12d83ef7fa23484ca924aa2655a6222e`는 기존 Eval 설정의 Qwen을 1회 호출하고 2156, 2181, 2154를 날짜순으로 인용했다. 첫 모델 내용은 1.99초, 전체는 2.97초였다. 10월 21일의 목표 날짜와 11월 1일의 자동 배포 전환은 근거 본문에 있었다. 10월 21일 기록에서 실제 배포일 확정을 확인할 수 없다는 점은 모델 응답보다 원문 표현이 더 좁다.

## 코퍼스 분리 확인

운영 Workspace 1의 읽기 전용 내보내기 결과를 로컬 DB에 적재했다. 문서 251개가 회의 41개에 속하며 본문은 평균 1,022자, 최대 4,029자다. 합성 Workspace 458은 문서 90개·회의 90개이며 평균 598자, 최대 1,227자다. `/workspaces`에서 각 코퍼스의 집계를 확인한다.

운영 문서는 섹션 구성이 다양하다. 핵심 요약은 251개에 있었고, 결정은 196개, 할 일은 124개, 제안은 43개, 배경 및 이유는 143개에서 확인됐다. 합성 문서는 모두 다섯 섹션을 포함한다. 이후 운영 코퍼스 실험에서 회의별 다양성을 확보할 때는 `meeting_id`를 기준으로 묶어야 한다. 질문·기대 근거가 있는 55개 비교와 현재 두 예제 실행은 458 코퍼스를 사용한다.

## Workspace 1 평가셋 초안

기존 Eval의 잠긴 `knot-workspace-458@1.30`에서 시나리오별 질문 유형과 기대 행동을 `.local/v130-reference.json`으로 읽어 온다. 필드는 `scenario`, `category`, `expectedType`, `question`, `expectedBehavior`다. 실제 정답의 출처는 Workspace 1의 저장 문서다.

```sh
.venv/bin/python snapshot.py --v130-reference
KNOT_EVAL_ENV_FILE=/path/to/knot/backend/.env.search-local .venv/bin/python build_dataset.py
.venv/bin/python extend_dataset.py
.venv/bin/python phase1.py
```

생성기는 운영 복사본의 저장 문서 전체를 기존 Eval Qwen에 제공한다. 문서별 독립 질문, 같은 회의의 복수 문서 질문과 후속 질문, 서로 다른 회의 비교 질문을 만든다. 같은 시나리오에 기본 질문과 구어체 질문을 담고, 인용 구절이 해당 문서 본문 또는 요약의 정확한 부분 문자열인지 확인한다. 최종 초안은 모든 문서를 인용한 경우 저장한다. 원문 일치는 기계적으로 확인하며 기대 행동과 질문의 정답성은 사람 검수 대상이다. 결과와 재개용 기록은 `.local/`에 둔다.

## 단계별 실험 순서

| 차수 | 실험 | 기준 |
| --- | --- | --- |
| 1 | 저장 문서 단위, 고정 토큰 창, Markdown 섹션 기반 Child를 같은 E5와 pgvector에서 비교 | 문서 Recall@10, nDCG@5, 근거 구절을 담은 Child Recall@10, 임베딩·검색 p50/p95 |
| 2 | 키워드와 벡터 후보를 RRF로 결합하고 단독 방식과 비교 | 동일 평가 사례의 지표 차이와 누락·순위 역전 |
| 3 | 후보 리랭킹과 선택한 Parent 문맥 확장 | 근거 정확도, 컨텍스트 토큰 수, 리랭킹·문맥 구성 지연 |
| 4 | 문서 찾기, 단일 질문, 여러 회의 종합으로 분기 | 날짜·권한 필터, 경로 판정 정확도, 문서 찾기의 생성 호출 0회 |
| 5 | 여러 회의의 근거를 확보하고 시간순으로 종합 | 회의별 사실 누락, 시점·변경 상태, 근거 충실도와 출처 정확도 |
| 6 | SSE, 캐시, 동시 요청 제한 | 첫 문서 결과 또는 첫 답변, p50/p95, 동시성, 실패·재연결 |
| 7 | 검수된 Gold Set으로 회귀 확인 | 검색과 답변 품질, 단계별 지연의 변화 |

1차의 Parent는 저장된 주제 문서다. Child는 최대 320토큰에 48토큰 겹침을 둔다. Markdown 헤더를 보존한 방식과 같은 토큰 예산의 고정 창을 비교한다. 각 청크는 문서 ID, 본문 또는 요약, 원문 문자 시작·끝을 저장한다. 질문 임베딩은 한 번 계산해 세 색인에 공통 사용한다. standalone 답변 사례만 비교 대상으로 삼는다.

종단간 실행에서는 질문 처리, 검색, 리랭킹, 문맥 구성, LLM 대기, 생성을 개별 시간으로 기록한다. 병렬로 실행하는 검색은 전체 경과 시간과 각 작업 소요 시간을 별도로 기록한다. 모델 서버 대기를 따로 관측할 수 없는 경우 미측정으로 표시한다. 문서 찾기는 결과 카드가 표시될 때까지, 생성 경로는 첫 답변과 완료까지 측정한다.

### 2026-11-11 Workspace 1 관측

문서 251개·회의 41개에서 339개 시나리오와 678개 질문을 생성했다. 기본·구어체 변형 전체에서 출처 위치 1,162개를 로컬 문서 본문 또는 요약과 대조했다. 시나리오는 문서별 251개, 같은 회의의 여러 문서 34개, 후속 질문 34개, 여러 회의 비교 20개다. 질문·기대 답변의 최종 검수는 남아 있다.

Standalone 답변 질문 562개에 대한 1차 벡터 검색 결과다. 임베딩은 p50 5.48ms, p95 8.21ms였고 각 색인에서 같은 질문 벡터를 사용했다. 생성 호출은 0회다.

| 색인 | 벡터 수 | 문서 Recall@10 | 문서 nDCG@5 | 근거 구절 Recall@10 | 검색 p50/p95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 문서 단위 | 251 | 92.6% | 0.804 | — | 0.93 / 2.11ms |
| 고정 길이 Child | 812 | 93.2% | 0.795 | 86.8% | 1.23 / 2.62ms |
| Markdown 섹션 Child | 1,319 | 92.3% | 0.802 | 74.1% | 1.36 / 3.14ms |

전체 색인에서 기대 구절을 포함한 청크의 비율은 고정 길이 99.6%, 섹션 100%였다. 상위 청크 10개에서 고유 문서 수는 각각 평균 6.67개와 5.43개였다. 실제 회의 간 비교 40문항에서는 문서 단위 Recall@10이 77.5%, 두 Child 방식은 75.0%였다. 2차에서 고정 길이와 문서 단위를 비교군에 두고 키워드 결합 및 중복 제거 효과를 따로 측정한다.

기존 로컬 Lab의 **평가셋 초안**과 **1차 청킹 비교** 탭에서 확인할 수 있다. 실험 결과는 `.local/workspace1-phase1.json`에 저장한다.


### 표현 변형 v0.2 초안

같은 339개 시나리오에 기본, 구어체, 오타, 간투사, 담화표지, 군더더기, 혼합형을 각각 339개씩 생성했다. 오타군은 글자 오타 294개와 띄어쓰기 누락 45개다. 일곱 표현의 기대 행동, 인용 위치, 앞선 대화와 기대 문서 ID는 시나리오마다 같다. 숫자는 통제된 변형에서 보존한다.

`extend_dataset.py`는 2,373문항의 평가셋 하나를 전용 로컬 DB의 `evaluation_datasets`에 등록하고 같은 내용의 로컬 파일을 쓴다. 기본·구어체의 0.1 초안과 첫 실행은 별도 로컬 파일로 보존했다.

1차 비교를 표현별 281개, 총 1,967개 standalone 답변 질문으로 다시 실행했다. 전체 문서 Recall@10은 문서 단위 94.15%, 고정 길이 Child 94.51%, 섹션 Child 94.26%였다. 근거 구절 Recall@10은 고정 길이 88.1%, 섹션 77.1%였다. 구어체의 문서 Recall@10은 각각 90.0%, 90.8%, 88.7%로 이 실험의 표현군 중 낮았다. 2차에서는 이 1,967개 질문과 기대 근거를 고정한다.
